Подключение…
Пробы временные. Сброс, Lab off и тайм-аут возвращают применённый профиль Body. Постоянные форму, рост и кожу сохраняй во вкладке Body в Avatar Studio.
Источник позы

game — обычное смешивание Wurm. bind — исходная поза. Выбранный клип проигрывается только на видимом локальном теле; движение персонажа по миру не меняется.

Сравнение бега

Все варианты из исходной библиотеки, заново перенесённые на родной скелет. Нажми вариант для непрерывного просмотра.

Возрастная кожа · временная проба Меняется только текстура локального тела. Форма тела выбирается отдельно. Сброс, Lab off и смена тела возвращают исходную кожу; проба не сохраняется в профиль.
Форма тела · временная проба 0% — 92% исходного размера, 50% — исходная голова, 100% — 108%. Независимо от формы тела.

Объём груди: 50% сохраняет текущий Build; 0% меньше, 100% больше. Мышцы и полнота остаются независимыми.

Ширина плеч: 0% уже, 50% исходная, 100% шире. Доступна для обоих полов.

Возраст выбирает форму тела и подходящую кожу; кожу затем можно изменить отдельно. Молодой сохраняет нынешний Build точно. Мышцы, полнота и грудь остаются доступными; голова и осанка сохраняются.

Build: мышцы 100%, полнота 0% = Original. Ползунки независимы; сочетания используют отдельные контрольные формы.

Выбранная доля применяется точно; остальные уменьшаются, если сумма превышает 100%. Доля 100% даёт полную форму при общей силе 100%. Остаток сохраняет Original. Save body в Studio сохраняет пробу; Reset возвращает профиль.
Поправка кости

Повороты вокруг собственного сустава, X/Y/Z в градусах. Применяются после смешивания и не накапливаются. Диапазон ±45°. Перемещения и полные локальные матрицы доступны через JSON/CLI.

Внешний буфер JSON
Проверка осей · спереди / сбокуСерый — базовый FK Wurm; зелёный — FK с поправкой. Оси выбранной кости: X красная, Y зелёная, Z синяя. Это координаты модели, не мировые координаты игры.
