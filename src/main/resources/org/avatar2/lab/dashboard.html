Источник позы

game — обычное смешивание Wurm. bind — исходная поза. Выбранный клип проигрывается только на видимом локальном теле; движение персонажа по миру не меняется.

Поправка кости

Повороты вокруг собственного сустава, X/Y/Z в градусах. Применяются после смешивания и не накапливаются. Диапазон ±45°. Перемещения и полные локальные матрицы доступны через JSON/CLI.

Внешний буфер JSON
Проверка осей · спереди / сбокуСерый — базовый FK Wurm; зелёный — FK с поправкой. Оси выбранной кости: X красная, Y зелёная, Z синяя. Это координаты модели, не мировые координаты игры.
