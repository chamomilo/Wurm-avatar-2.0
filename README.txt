INSTALL / UPDATE
1. Close Wurm Unlimited. Requires a compatible Wurm Client Mod Launcher.
2. Back up mods/avatar2/avatar-profile.properties if you already use Avatar.
3. Extract this ZIP into WurmLauncher, merging the mods folder and replacing
   mods/avatar2.properties. Keep your profile and its backups.
4. Start the client. Open Avatar Studio in HUD Settings, or type /avatar2 in
   the F1 console. Versioned JARs from older releases may be removed manually
   after a successful update; preserve profile files.

CONTROLS
Body changes preview immediately. Save body keeps the appearance; Revert body
restores the last saved profile. Avatar on/off restores the original model.
Lab tests are temporary. Reset test / Lab off restores the applied Body profile.
Saving from Lab keeps the appearance; animation tests stay temporary.

SHARED SETTINGS
Open the Chamomilo updater and select Settings on the Avatar 2.0 card.
Studio visibility and diagnostic logging apply immediately. Profile/resource
paths apply after restart. Changing the profile path does not move the file.
Leave the resource-pack default unchanged to follow future releases.
User overrides: ~/.chamomilo/mod-settings/avatar2.properties
Select English, Portuguese (Brazil), German or Russian in the shared updater.

Armour fitting remains in development. The nearby-camera head mask hides the
interior; it does not add collision to free look.

РУССКИЙ
Установка: закройте игру, сохраните копию своего avatar-profile.properties,
распакуйте архив в WurmLauncher с объединением папки mods и заменой
mods/avatar2.properties. Сохранённый профиль не удаляйте.

Откройте Avatar Studio через настройки HUD или командой /avatar2 в консоли F1.
Во вкладке Body изменения видны сразу. Save body сохраняет внешность,
Revert body возвращает сохранённую. Пробы Lab временные: Reset test или
Lab off возвращает применённый профиль. Анимационные пробы не сохраняются.

В общем окне Chamomilo нажмите Settings на карточке Avatar 2.0. Видимость
Studio и диагностика меняются сразу, пути профиля и ресурсов — после
перезапуска клиента. Настройки сохраняются автоматически. Русский язык
выбирается в общем переключателе языка updater. Путь к пакету ресурсов
лучше оставлять стандартным: тогда обновления подхватят новый пакет.

Руководство с картинками находится на GitHub по ссылке в начале файла.
